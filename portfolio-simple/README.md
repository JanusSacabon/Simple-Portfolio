# portfolio-simple

Simple static HTML/CSS portfolio for easy GitHub + Vercel deployment.

## Files

- `index.html`
- `style.css`
- `JanusXavier_Sacabon_RESUME.pdf` (you need to add this file)

## How to deploy on Vercel

1. Upload this folder to a GitHub repository.
2. Import that repository in Vercel.
3. Framework preset: `Other`.
4. Root directory: `.`
5. Deploy.
